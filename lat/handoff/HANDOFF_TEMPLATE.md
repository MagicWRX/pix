# HANDOFF TEMPLATE

Copy this shape for every INBOX / OUTBOX entry.

```markdown
### YYYY-MM-DD — <from agent> → <to agent / Brian> — <short title>
- **Task:** what was asked, in one or two lines, in the requester's own terms.
- **Claim:** the CLAIMS.md row this work ran under (item + claimed-at).
- **Did:** what was actually done — no more, no less.
- **Evidence:** commit SHAs, file paths, check results, URLs. Anything "verified" names how.
- **Not done / blockers:** anything incomplete, stated plainly, with what unblocks it.
- **Next:** the single next step, and whose hands it's in.
```
